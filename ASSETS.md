# Asset sources

All image files are stored in `public/assets/` and used by the website.

- `bubble-original.png`: supplied by the creator as “Irisierende Seifenblase mit Glanzreflexen.png”; used for the large bubble artwork.
- `reef.png`: generated underwater reef background used in the aquarium preview.
- `clown.png`, `angel.png`, `tetra.png`, `goldfish.png`: generated fish cutouts used in the preview, resident cards and decoration.
- `bubble.png`: generated transparent bubble used for rising bubbles.
- `dots.png`: generated dotted texture used for the page background.
